## 第 1 节 · H5 零回归（US4，最优先）

```bash
cd frontend && npm run build:h5
```

浏览器用 `http://localhost:10086` 打开（不要用 LAN IP，会被 CORS 拦）：

- [ ] H5 首页高德地图正常显示
- [ ] 有点位时地图上 marker 显示，marker 上能看到信源数
- [ ] 点击 marker 能打开点位详情
- [ ] 搜索某地名后地图自动 fitView 到点位范围
- [ ] 定位成功后地图居中到用户位置
- [ ] 缩放控件、比例尺正常
- [ ] 「一键导航」正常（H5 走 window.open 打开高德）
- [ ] 与改动前肉眼对比无差异

> 关键：`MapCanvas.tsx`（H5 文件）本 spec 计划「不碰」（仅可能改一行类型 import）。若上面任一项回归，先 `git diff frontend/src/components/MapCanvas.tsx` 看是否被误改。

## 第 2 节 · 小程序地图显示（US1）

```bash
cd frontend && npm run build:weapp
```

微信开发者工具打开 `frontend/dist/`：

- [ ] 首页地图区显示一张真实地图（不再空白）
- [ ] 可手指拖动地图
- [ ] 可双指/滚轮缩放地图

---

## 第 3 节 · 点位 marker（US2）

- [ ] 有 N 个点位数据时，地图上出现 N 个 marker
- [ ] 每个 marker 能看出该点位的信源数（callout 气泡 / label 标签）
- [ ] 点击任一 marker → 打开该点位详情，内容正确
- [ ] 当前区域 0 点位时，地图正常显示、不空白、不报错

---

## 第 4 节 · 地图居中（US3）

- [ ] 定位成功后，地图中心在用户位置附近、缩放级别合理
- [ ] 搜索一个有结果的地名（如「杭州露营」）→ 地图视野移动到点位范围
- [ ] 搜索一个无结构化点位的地名 → 地图视野移动到该地名中心区域
- [ ] 定位被拒时，地图回退到默认城市视野，不卡死

---

## 第 5 节 · 浮层不被遮挡（FR-006，重点核验）

小程序首页地图之上的浮层元素，逐一确认**可见且可点**：

- [ ] 顶部搜索框可见、可输入
- [ ] 地图/列表模式切换可见、可点
- [ ] 结果分类 tab 可见
- [ ] 筛选栏可见、可点
- [ ] 底部列表/sheet 面板可见、可拖

> 若有元素被地图盖住 → 同层渲染未生效，需按 research.md D2 回退方案（局部 cover-view）处理。

---

## 第 6 节 · 一键导航（US5）

- [ ] 小程序端点位详情点「一键导航」→ 唤起微信位置查看页（可进一步「到这里去」）
- [ ] 不再是「点了无反应」
