# Quickstart 真机验证清单: 修复微信小程序地图初始视野

**Feature**: 016-fix-weapp-map-view | **Date**: 2026-05-23

⚠️ **本功能验收以真机调试为准**——微信开发者工具模拟器的 `<map>` 视野行为与真机不一致，不作通过依据（spec 关键约束）。

## 一、构建

- [ ] `cd frontend && npm run build:weapp` —— 构建成功、无报错
- [ ] `cd frontend && npm run build:h5` —— 构建成功（H5 零回归基线）

## 二、真机核验（微信开发者工具 → 真机调试，用手机扫码）

- [ ] **初始居中**：手机打开小程序、定位成功后，不做任何操作——地图画面中心就在用户实际位置附近，定位蓝点居中可见（不再「蓝点一处、画面一处」）
- [ ] **定位更新跟随**：定位坐标由兜底坐标更新为真实 GPS 后，地图视野跟着移动到真实位置
- [ ] **搜索更新跟随**：搜索出点位后，地图视野移动到点位范围；搜索到地名但无点位时移动到地名中心
- [ ] **无崩溃**：地图加载、定位、搜索、拖动全程无 `<map>` 渲染崩溃（spec-014 的 `Cannot read property 'lat'` 不复现）
- [ ] **定位失败兜底**：拒绝定位授权时，地图居中到兜底默认坐标（杭州），不卡在无关位置、不崩
