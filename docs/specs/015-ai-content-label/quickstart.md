# Quickstart 验证清单: AI 生成内容应用内合规标识

**Feature**: 015-ai-content-label | **Date**: 2026-05-22

实现完成后，按本清单逐项人工核验。纯 UI 文案改动，无前端自动化测试。

---

## 一、构建

- [ ] `cd frontend && npm run build:h5` —— 构建成功，无报错
- [ ] `cd frontend && npm run build:weapp` —— 构建成功，无报错

## 二、H5 端核验（浏览器）

完成一次搜索后：

- [ ] **AI 提炼结果区**：能看到「AI 生成整理」显式标识
- [ ] **点位卡片**（列表模式 + 地图模式底部 sheet 的紧凑卡片）：每张卡片都能看到「AI 生成整理」标识
- [ ] **点位详情**：点开任一点位详情，能看到「AI 生成整理」标识（既有 disclaimer 仍在）
- [ ] **来源线索卡**：若有未入图线索，线索卡上能看到「AI 生成整理」标识
- [ ] **风险提示**：结果列表区顶部能看到一处「仅供参考、请自行核实」之意的风险提示，且只出现一次（不逐张卡片重复）
- [ ] **文案逐字核对**：标识文字为「AI 生成整理」，含「AI」与「生成」字样（符合 GB 45438-2025）

## 三、边界场景核验（H5）

- [ ] **空状态**：未搜索时的引导页 / 无结果提示处，不出现标识与风险提示
- [ ] **AI 提炼结果区未渲染但有点位卡片**：构造「搜索出点位、但 AI 提炼文字为空或告警」的状态——风险提示仍可见、不缺失
- [ ] **网络错误占位**：报错占位上不出现标识与提示

## 四、微信小程序端核验（微信开发者工具）

- [ ] AI 提炼结果区、点位卡片、点位详情、来源线索卡 上标识均可见，与 H5 表现一致
- [ ] 风险提示一处可见，与 H5 一致
- [ ] 控制台无 WXSS 报错（重点：新增 CSS 无 `*` 选择器导致的编译失败）

## 五、H5 零回归核验

- [ ] AI 提炼结果区：原有标题、正文、信源 chip、meta 行 与改动前一致，仅多出标识
- [ ] 点位卡片（紧凑 + 完整两模式）：原有名称、设施 badge、摘要、信源行、导航按钮 布局未被标识/提示挤乱
- [ ] 点位详情：原有信源列表、设施格、按钮 与改动前一致
- [ ] 来源线索卡：原有名称、理由、来源 与改动前一致
