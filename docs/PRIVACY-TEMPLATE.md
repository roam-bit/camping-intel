## 二、我们收集哪些信息、为什么收集

### 2.1 必需信息（不提供将无法使用核心功能）

| 我们收集 | 拿来干啥 | 法律依据 |
|---|---|---|
| **大致地理位置**（经纬度，精度约 100 米）| 计算"周边露营点"、地图初始定位 | 《个人信息保护法》第 13 条 - 履行合同所必需；第 28 条 - 敏感个人信息单独同意 |
| **您输入的搜索关键词**（如"杭州周边免费露营地"）| 调用 AI 联网搜索 + 整理结果 | 同上 |
| **您主动提交的反馈**（"是否可停车"、"是否可过夜"、风险标记、文字评论）| 让其他用户看到真实点位情况 | 用户主动提交 |

⚠️ **关于位置信息的特别说明**（《个保法》第 28 条规定为"敏感个人信息"）：
- 我们**仅在您打开本产品时**请求位置权限
- 您可以**随时拒绝**位置权限（系统设置中关闭即可）
- 拒绝后，我们将**默认使用"杭州"作为搜索中心**，您仍可手动输入其他地点搜索
- 我们**不会持续后台追踪**您的位置

### 2.2 自动收集的信息（用于服务运行 + 故障排查）

| 我们收集 | 拿来干啥 | 是否能关 |
|---|---|---|
| 设备类型（iOS / Android / 微信 / 浏览器） | 适配显示 | 不能（看到我们网页就被收集了）|
| 请求时间 / IP 地址 | 后端日志（故障排查 + 防滥用）| 不能 |
| 您查看过的信源 URL（仅存在您自己手机里）| 显示"已查看"标记 + 求证进度 | 清浏览器缓存即清 |

**注意**：您查看过的信源链接是**只存在您自己设备的 localStorage**，**不上传到我们服务器**。

### 2.3 我们 **不** 收集的信息

- ❌ 您的真实姓名、身份证号、手机号、邮箱
- ❌ 您的通讯录、相册、麦克风、摄像头
- ❌ 您手机里其他 App 的使用情况
- ❌ 您的支付信息、银行卡

| 给您提供 AI 搜索服务 | 把您的关键词 + 大致位置发给"火山方舟"AI 服务（见第五节）并整理回答 |

- 用您的数据训练 AI 模型
- 向境外传输您的数据

## 四、AI 生成内容说明（重要）

根据《生成式人工智能服务管理暂行办法》要求，我们明确告知：

1. **AI 生成内容的范围**：本产品中标注 ⚡ "AI 生成" 或 "AI 提炼结果" 的文字内容，是 AI 自动整理网络公开信源的结果，**不代表本产品立场，也不构成对您行为的建议**。

2. **可能存在的局限**：
   - AI 可能产生**事实性错误**（如把"商业营地"错标为"免费"）
   - 信息可能**已过时**（网友实测可能是几个月前的）
   - **不构成法律 / 安全建议**

3. **您的义务**：
   - **前往任何点位前请通过"信源链接"自行核验**
   - **遵守当地法律法规**和景区管理要求
   - 露营 / 驻车的实际可行性以**现场和官方信息为准**

4. **我们对 AI 内容的处理**：
   - 每个 AI 生成结论都附**真实可点的信源 URL**
   - 信源页面**与本产品无关联**，您打开后属于自行访问第三方网站
   - 我们**不对信源页面的真实性**作担保

## 八、信息安全

我们采取以下措施保护您的信息：

1. **传输加密**：H5 端 / API 全程 HTTPS
2. **存储加密**：数据库密码字段加密存储
3. **访问控制**：后端运维仅运营者本人可登录
4. **限流防滥用**：单 IP 单分钟内请求次数限制
5. **审计日志**：所有数据库操作有记录

⚠️ **请注意**：互联网环境不是 100% 安全的，我们无法对所有可能发生的网络攻击提供绝对保证。**如发现安全事件**，我们将在 **72 小时内**通过本产品内公告或您预留的联系方式通知您。
